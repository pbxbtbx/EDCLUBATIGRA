# Identidad facilitada por el usuario

- `atigra-makers-oficial.svg`: logo oficial facilitado por el usuario como `Llavero_Atigra_Makers_inkscape.svg`. Se conserva byte por byte, sin redibujar, recolorear ni sustituir sus letras. Se presenta sobre blanco para conservar la legibilidad de «Makers».
- `atibot-expresiones.png`: adaptación generada a partir de la imagen de ATIBOT adjuntada por el usuario el 15 de octubre de 2026, a petición suya. Contiene tres celdas iguales de 724 × 724: curioso, pensativo y sorprendido. Ojos abiertos con esclerótica blanca, iris verdes y pupilas negras. Fondo transparente. Estas expresiones son adaptaciones solicitadas, no una afirmación de aprobación oficial adicional. El recorte para cada expresión se hace al mostrar el sprite mediante CSS, sin alterar el logo.

Las imágenes se sirven desde la propia aplicación; no dependen de un CDN ni de una API de generación en tiempo de ejecución. La imagen del usuario es la referencia del personaje, y reemplaza al robot provisional de CSS de las versiones iniciales.
